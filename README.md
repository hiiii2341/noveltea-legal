# noveltea-legal

Public Support, Privacy Policy, and Terms of Use pages for the NovelTea iOS app
(SIER Technologies Inc.), served by GitHub Pages at https://thenoveltea.com (domain at Namecheap; `CNAME` file sets it). Layout follows dailydove.app's
pages, recoloured to the NovelTea brand.

| Page | File | URL path |
|---|---|---|
| Home | `index.html` | `/` |
| Support (App Store Connect "Support URL") | `support.html` | `/support` |
| Privacy Policy | `privacy.html` | `/privacy` |
| Terms of Use | `terms.html` | `/terms` |

Styles: `shared.css`. Icons: `assets/` (made from the book-and-tea logo).

Edit the HTML, commit to `main`, and GitHub Pages redeploys in about a minute.
When a policy's text changes, bump its "last revised" date at the top and bottom.

After editing `shared.css`, bump the `?v=N` on its `<link>` in all four pages so browsers drop the cached copy.
